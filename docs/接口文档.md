# 接口文档

Base URL: `http://127.0.0.1:8001`

## 健康检查

### GET /api/health

**响应**：
```json
{"status": "ok", "message": "学科知识整合智能体运行中"}
```

---

## 教材管理

### POST /api/upload

上传教材文件（PDF/MD/TXT）。

**请求**：`multipart/form-data`，字段 `file`

**响应**：
```json
{
  "id": "book_00123",
  "filename": "生理学.txt",
  "title": "生理学",
  "format": "txt",
  "size_bytes": 1675250,
  "status": "done",
  "total_pages": 397,
  "total_chars": 385000,
  "chapters": [
    {
      "chapter_id": "ch_01",
      "title": "第一章 绪论",
      "page_start": 1,
      "page_end": 15,
      "content": "生理学是研究生物体正常生命活动规律的科学...",
      "char_count": 8500
    }
  ]
}
```

### GET /api/textbooks

获取所有已上传教材列表。

**响应**：`TextbookDetail[]`

### GET /api/textbooks/{textbook_id}

获取单本教材详情（含章节内容）。

## 知识图谱

### POST /api/graph/build/{textbook_id}

为指定教材构建知识图谱（调用LLM逐章提取知识点）。

**响应**：
```json
{
  "status": "done",
  "textbook_id": "book_00123",
  "nodes": 25,
  "edges": 32
}
```

### GET /api/graph/data

获取所有教材的合并图谱数据（前端可视化用）。

**响应**：
```json
{
  "nodes": [
    {
      "id": "book_00123_node_001",
      "name": "动作电位",
      "definition": "细胞受到刺激后膜电位发生的快速可逆倒转",
      "category": "核心概念",
      "chapter": "第二章 细胞的基本功能",
      "page": 35,
      "textbook_id": "book_00123",
      "textbook_name": "生理学",
      "frequency": 1,
      "color": "#ff6b6b"
    }
  ],
  "edges": [
    {
      "source": "book_00123_node_001",
      "target": "book_00123_node_002",
      "relation_type": "prerequisite",
      "description": "理解动作电位需要先掌握静息电位"
    }
  ]
}
```

### GET /api/graph/data/{textbook_id}

获取单本教材的知识图谱数据。

### GET /api/graph/build-status/{textbook_id}

查询构建状态。

**响应**：
```json
{"textbook_id": "book_00123", "status": "done"}
```

## 跨教材整合

### POST /api/integration/run

执行跨教材知识图谱整合。

**响应**：
```json
{
  "original_total_chars": 8790630,
  "merged_total_chars": 2410000,
  "compression_ratio": 0.274,
  "decisions": [
    {
      "decision_id": "merge_001",
      "action": "merge",
      "affected_nodes": ["book_01_node_015", "book_03_node_032"],
      "result_name": "炎症",
      "reason": "两本教材都讲解了炎症概念，保留病理学版本因其描述最系统完整",
      "confidence": 0.92
    }
  ],
  "merged_graph": { "nodes": [...], "edges": [...] }
}
```

### GET /api/integration/status

获取最新整合结果。

### POST /api/integration/decisions/{decision_id}

修改某项整合决策。

**查询参数**：
- `action`：merge | keep | remove
- `reason`：（可选）修改理由

## RAG问答

### POST /api/rag/index

对已上传教材建立向量索引（分块→BGE嵌入→FAISS）。

**响应**：
```json
{"status": "indexed", "total_chunks": 1247}
```

### POST /api/rag/query

RAG问答。

**请求**：
```json
{"question": "什么是炎症？"}
```

**响应**：
```json
{
  "question": "什么是炎症？",
  "answer": "炎症是机体对致炎因子的损伤所发生的以防御为主的局部组织反应...",
  "citations": [
    {
      "textbook": "病理学",
      "chapter": "第四章 炎症",
      "page": 78,
      "relevance_score": 0.92
    }
  ],
  "source_chunks": ["炎症(inflammation)是具有血管系统的活体组织..."]
}
```

### GET /api/rag/status

查询RAG索引状态。

**响应**：
```json
{"indexed_textbooks": 7, "total_chunks": 1247, "has_index": true}
```

## 多轮对话

### POST /api/dialogue

发送对话消息，系统返回回复和可能更新的决策。

**请求**：
```json
{
  "message": "为什么把生理学里的炎症和病理学里的炎症反应合并了？",
  "history": []
}
```

**响应**：
```json
{
  "reply": "语义分析显示两处描述的核心概念一致（余弦相似度0.94）...",
  "history": [
    {"role": "user", "content": "为什么把生理学里的炎症和病理学里的炎症反应合并了？"},
    {"role": "assistant", "content": "语义分析显示两处描述的核心概念一致..."}
  ],
  "decision_updates": []
}
```
