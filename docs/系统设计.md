## 数据流

一次完整的「上传教材 → 构建图谱 → 整合 → 问答」流程：

1. **上传**：教材文件通过 `POST /api/upload` 上传，后端解析章节结构存入内存
2. **图谱构建**：`POST /api/graph/build/{id}` 触发，逐章调用 DeepSeek API 提取知识点和关系，每条知识点包含名称、定义、类别、所属章节
3. **图谱数据**：`GET /api/graph/data` 返回所有教材的合并图谱数据（节点+边），前端 ECharts 渲染力导向图
4. **跨教材整合**：`POST /api/integration/run` 执行 BGE Embedding 语义对齐，高相似知识点对送 LLM 判断合并，压缩到 30%
5. **RAG索引**：`POST /api/rag/index` 将教材内容分块（600字/chunk，100字重叠），BGE 向量嵌入，存入 FAISS
6. **RAG问答**：`POST /api/rag/query` 将问题向量化，检索 Top-5 chunk，注入 LLM prompt 生成带引用的回答
7. **对话**：`POST /api/dialogue` 支持教师用自然语言讨论和修改整合决策

## 技术选型及理由

| 技术 | 选择 | 理由 |
|------|------|------|
| 后端框架 | FastAPI | 异步支持好、生态丰富、自动生成 OpenAPI 文档 |
| LLM | DeepSeek API | 中文能力强、价格低、适合大量调用 |
| Embedding | BGE-small-zh | 中文优化、本地运行免费、轻量（~100MB） |
| 向量库 | FAISS | 轻量、零部署、Python原生支持 |
| 前端框架 | Vue 3 + Vite | 响应式数据绑定、SFC组件化、HMR热更新 |
| 图谱可视化 | ECharts | 力导向图内置、中文文档好、Vue集成简单 |
| 文件解析 | PyMuPDF | PDF解析成熟稳定，章节识别准确 |

## API 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/health | 健康检查 |
| POST | /api/upload | 上传教材文件 |
| GET | /api/textbooks | 获取教材列表 |
| GET | /api/textbooks/{id} | 获取教材详情（含章节） |
| POST | /api/graph/build/{id} | 构建知识图谱 |
| GET | /api/graph/data | 获取合并图谱数据 |
| GET | /api/graph/data/{id} | 获取单本教材图谱 |
| GET | /api/graph/build-status/{id} | 查询构建状态 |
| POST | /api/integration/run | 执行跨教材整合 |
| GET | /api/integration/status | 获取整合结果 |
| POST | /api/integration/decisions/{id} | 修改整合决策 |
| POST | /api/rag/index | 建立RAG向量索引 |
| POST | /api/rag/query | RAG问答 |
| GET | /api/rag/status | 查询索引状态 |
| POST | /api/dialogue | 发送对话消息 |
